1. DESCRIPCIÓN DEL JUEGO
================================================================================

Nombre: Xela
Tipo: Combates 1 vs 1 en tiempo real (vs IA o vs amigos mediante código de sala de 6 caracteres).
Vista: Side-view 2D.
Mecánica: Movimientos simples (ataque ligero, ataque fuerte, especial, bloqueo).
Público: Jóvenes (teens y jóvenes adultos).
Estilo visual: Cartoon moderno + identidad de marca Xela (logo XA blanco sobre negro).

Características principales:
- Login / Registro con correo electrónico + Google + recuperación de cuenta
- Perfil de usuario con nombre + selección de avatar predefinido
- Crear sala → genera código de 6 caracteres
- Unirse a sala con código
- Combate vs IA (3 niveles de dificultad)
- Combate vs amigo en tiempo real
- Guardado completo de progreso en Firestore
- Ranking personal y global
- Diseño 100% responsive (móvil + PC)
- Páginas legales: Términos y Condiciones, Política de Privacidad y Cookies
- Logo oficial de Xela presente en landing, header y favicon

6. MODELO DE DATOS
================================================================================

### Firestore → users/{uid}
{
  uid: string,
  email: string,
  displayName: string,
  avatarId: string,
  wins: number,
  losses: number,
  winStreak: number,
  unlockedFighters: string[],
  rankingPoints: number,
  createdAt: timestamp,
  lastLogin: timestamp
}

### Realtime Database → rooms/{roomCode}
{
  host: string,
  guest: string | null,
  status: "waiting" | "ready" | "fighting" | "finished",
  hostFighter: string,
  guestFighter: string | null,
  hostReady: boolean,
  guestReady: boolean,
  createdAt: number
}

================================================================================
7. REGLAS DE SEGURIDAD
================================================================================

### Firestore Rules:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == userId;
    }
    match /rankings/{document=**} {
      allow read: if request.auth != null;
      allow write: if false;
    }
  }
}

### Realtime Database Rules:
{
  "rules": {
    "rooms": {
      "$roomCode": {
        ".read": "auth != null",
        ".write": "auth != null",
        ".validate": "newData.hasChildren(['host', 'status', 'createdAt'])"
      }
    }
  }
}
